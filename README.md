## 🌟 Ключевые Возможности

### 📸 1. ИИ-Распознавание Скриншотов Матчей (Gemini Vision OCR)
- **Мгновенный ввод результатов:** игроку достаточно прикрепить скриншот послематчевой статистики из EA FC / FIFA.
- **Перцептивное распознавание:** модель считывает только то, что видно на экране — счёт, голы и ассисты по левой и правой стороне. Клубы, стороны и составы определяются потом детерминированно, в Python и SQLite.
- **Распознавание составов:** фото состава превращается в заявку клуба с позициями игроков.
- **Устойчивое определение клуба:** опечатки OCR, сокращения и транслит (`Ман Сити`, `Барса`, `bayern`) сводятся к каноническому названию; неоднозначные формы (`Реал`, `Интер`) намеренно не угадываются.

### 🏆 2. Дивизионы, Туры и Кубки
- **Дивизионы:** лига разбита на 5 дивизионов по 16 клубов, у каждого свои туры, таблица, расписание, бомбардиры, долги и форумный топик.
- **Туры:** статусы `scheduled → open → closed`, дедлайны, досрочное закрытие с подтверждением.
- **Кубки:** серии плей-офф по стадиям с подсчётом побед и автоматическим продвижением победителя.
- **Двухэтапная верификация:** результат подтверждает соперник, спорные матчи уходят администратору.

### ⏳ 3. Регламент Долгов и Варнов
- Несыгранный матч становится долгом в дедлайн тура (или при досрочном закрытии — с сохранением оставшегося времени).
- Автоматические напоминания в ЛС, мягкое предупреждение, эскалация админам дивизиона, затем глобальным админам.
- Варны выдаются **только** вердиктом (ТП / ТН), не автоматикой; сыгранный долг снимает по варну обоим. Лимит — 4 варна.
- Заморозки и продления матчей сдвигают все сроки регламента.

### 🤖 4. ИИ-Аналитик «Темшик»
- Активируется в ЛС и в чатах по слову `темшик` (*«Темшик, какие шансы у команды на топ-3?»*).
- Считает шансы по очкам, оставшимся турам, разнице мячей и форме (`W-D-L`).
- Знает регламент, историю лиги и отвечает в рамках дивизиона.
- Публикует превью и дайджест тура в топик АНАЛИТИКА.

### 🎨 5. Инфографика
- Турнирные таблицы, карточки клубов и игроков, расписания клубов, топ бомбардиров и ассистентов, дайджесты туров.
- Рендер на Pillow в Retina-качестве (2x/3x), палитра — по теме дивизиона.

### 🎰 6. Logovo.bet (Telegram Mini App)
- Замкнутая **виртуальная** экономия монет 🪙 — реальные деньги не участвуют нигде.
- Ординары и экспрессы на матчи лиги и серии кубков, кэшаут, лимиты (не больше 12 открытых купонов), единый риск-движок.
- Геймификация: уровни, достижения, серии.
- Детектор договорных матчей (Integrity Engine) — только флаг для супер-админа, ставки не блокирует.

### ⚙️ 7. Панель Администратора
- Управление турами, дедлайнами, кубковой сеткой и форумными топиками дивизионов.
- Технические результаты (ТП / ТН), разрешение споров, ручная корректировка счёта.
- Роли: глобальные админы и админы отдельных дивизионов; режим `LOGOVO_LOCKDOWN` закрывает бота для всех, кроме глобальных админов.

## 🚀 Быстрый Запуск

### 1. Клонирование и Установка Зависимостей

```bash
git clone https://github.com/sp1r1tVSA/logovobot.git
cd logovobot

# Создание и активация виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

### 2. Настройка Переменных Окружения (`.env`)

Скопируйте `.env.example` в `.env` и заполните. Минимальный набор:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
ADMIN_IDS=123456789,987654321
LEAGUE_SQLITE_PATH=league.db

# Gemini: OCR скриншотов и чат Темшика — отдельные ключи, чтобы лимиты не пересекались.
# Можно указать несколько ключей через запятую — они ротируются при 429.
GEMINI_API_KEY=AIzaSy_ocr_key1,AIzaSy_ocr_key2
GEMINI_CHAT_API_KEY=AIzaSy_chat_key1

# Mini App (Logovo.bet)
WEBAPP_URL=https://your-domain.example
API_PORT=8080

# true — бот доступен только глобальным админам
LOGOVO_LOCKDOWN=false
```

Полный список (rate limit API, live-провайдер, Integrity Engine и т.д.) — в `.env.example`.

### 3. Локальный Запуск

```bash
python main.py
```

### 4. Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -q
```

Тесты идут параллельно (`-n auto`), каждый файл получает свою временную БД — рабочая `league.db` не затрагивается.

## 🐳 Деплоймент

**Docker:**

```bash
docker build -t logovobot .
docker run -d --env-file .env -e LEAGUE_SQLITE_PATH=data/league.db \
  -v $(pwd)/data:/app/data -p 8080:8080 logovobot
```

База лежит в смонтированной папке `data/` и переживает пересборку контейнера.

**Systemd (VPS):**

```bash
sudo nano /etc/systemd/system/logovobot.service
```

```ini
[Unit]
Description=LogovoBot Telegram Bot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/logovobot
ExecStart=/root/logovobot/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now logovobot
journalctl -u logovobot -f
```

## 💬 Команды Бот-Системы

Любая текстовая команда «Темшик ...» работает в рамках одного дивизиона, и бот определяет
его автоматически:

1. **в форумном топике** — по привязке топика к дивизиону;
2. **в группе дивизиона** — по привязке группы;
3. **в личке с ботом** — по дивизиону клуба тренера.

Дивизион можно указать и явно — последним аргументом: `Дивизион 2`, `див 2` или кодом
`DIV_2`. Если дивизион определить не удалось (например, в общем чате вне топика), бот не
показывает кросс-дивизионные данные, а выводит список доступных дивизионов.

### 👤 Команды Игрока
- `/start` — Главное меню: 🎰 Logovo.bet, 👤 Мой кабинет, 🏆 Дивизионы, 🆘 Поддержка.
- `/register` — Регистрация профиля.
- `/table` — Турнирная таблица дивизиона.
- `/club` — Карточка клуба.
- `/cup` — Кубковая сетка.
- `/overview` — Сводка по лиге.
- `/summon` — Позвать тренера клуба на матч.
- `/bet` — Открыть Logovo.bet (ставки живут только в Mini App).
- `👤 Мой кабинет` — Мои матчи, отправка результата и состава, споры, 📜 правила турнира.

**Текстовые команды «Темшик ...»:**
- `Темшик помощь` — Полный список команд с учётом ваших прав.
- `Темшик дивизионы` — Список активных дивизионов лиги.
- `Темшик таблица [дивизион]` — Турнирная таблица (графика + кнопка обновления).
- `Темшик бомбардиры [число] [дивизион]` — Топ бомбардиров: без числа — карточка, с числом — список.
- `Темшик ассистенты [число] [дивизион]` — Топ ассистентов.
- `Темшик долги [дивизион]` — Несыгранные матчи дивизиона с тегами участников.
- `Темшик состав [клуб]` — Фото и состав заявленного клуба.
- `Темшик карточка [клуб]` — Инфокарточка клуба.
- `Темшик позвать [клуб]` — Тегнуть тренера клуба.
- `темшик [вопрос]` — Свободное общение с ИИ-аналитиком.

### ⚙️ Команды Администратора
- `👑 Админ-панель` — Туры, дедлайны, кубки, матчи, клубы и составы.

**Туры и топики:**
- `Темшик закрыть тур [номер] [дивизион]`
- `Темшик топики [дивизион]` — Статус настройки форумных топиков.
- `/naznachit_topik <div_id>` / `/perenaznachit_topik <div_id>` / `/snyat_topik` — Привязка текущего топика.
- `/topiki <div_id>` — Топики дивизиона, `/diviziony` — сводка по всем дивизионам.
- `/bind_group` — Привязать группу к дивизиону.

**Составы и клубы:**
- `Темшик +игрок [клуб] [имена через запятую]` / `Темшик -игрок [клуб] [имя]`
- `Темшик позиция [клуб] [POS] [имя]` — Смена позиции (GK, CB, CM, ST и т.д.).
- `Темшик переименовать игрока [клуб] [старое] -> [новое]`
- `Темшик привязать клуб @username [клуб]`
- `Темшик тег @username [клуб]` / `Темшик обновить теги [дивизион]` — Плашки клубов в чате.
- `/squads` — Статус загрузки составов, `/add_player`, `/import_players`.

**Дисциплина:**
- `Темшик варн @username [причина]` / `Темшик снять варн @username` / `Темшик варны`
- `Темшик автоварны` или `/check_debts` — Ручной прогон проверки долгов (напоминания и эскалация; варны он не выдаёт).
- `/unwarn`, `/reset_warns` — Снятие варнов.

**Аналитика и контроль:**
- `/round_preview`, `/round_digest` — Превью и дайджест тура вручную.
- `/admin_bets` — Лента ставок, `/integrity` — подозрения на договорные матчи.
