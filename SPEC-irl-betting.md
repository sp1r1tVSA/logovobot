# SPEC — Ставки на реальные матчи («IRL-ставки»)

Status: draft, awaiting go-ahead. Decisions below were confirmed by the owner; items under
**Assumptions** are mine and need a yes/no.

## Objective

Каждый день бот выбирает топ-матч (или несколько) реального футбола из самого приоритетного
турнира, у которого сегодня есть игры. Игроки Logovo.bet ставят на него виртуальные монеты по
коэффициентам одного фиксированного букмекера. После матча ставки рассчитываются автоматически.

## Confirmed decisions

| Тема | Решение |
|---|---|
| Источник | API-Sports (адаптер уже есть), коэффициенты **одного фиксированного букмекера** (`IRL_BOOKMAKER_ID`) |
| Выбор матча | Авто по списку лиг в порядке приоритета + превью админу, который может заменить матч или добавить второй |
| Рынок | Только **1X2**, счёт основного времени (90 мин + добавленное; без допвремени и пенальти) |
| Лимиты | Ставка ≤ **1000 🪙**, **одна ставка на игрока на матч** |
| Расчёт | Авто по финальному счёту провайдера, с защитой от ранних/сбойных данных |

Из лимитов следует: только одиночные ставки — без экспрессов, кэшаута, лимита открытых купонов.

## Design

**Отдельный модуль, не `matches`/`markets`.** `markets.match_id` — FK на `matches(id)` (матчи
FIFA-лиги); IRL-матчи туда не вписать без обхода FK. Поэтому новая миграция `035` добавляет:

- `irl_matches` — `id`, `provider_fixture_id` (UNIQUE), `league_id`, `league_name`, `home`, `away`,
  `kickoff_at` (MSK), `status` (`draft | open | closed | settled | void`), `odd_home/draw/away`,
  `odds_updated_at`, `result` (`home|draw|away`), `home_goals`, `away_goals` (основное время),
  `bet_day` (MSK-дата), `picked_by` (`auto|admin`), `created_at`, `settled_at`.
- `irl_bets` — `id`, `user_id`, `irl_match_id`, `outcome` (`home|draw|away`), `amount`, `odd`
  (фиксируется в момент ставки), `potential_win`, `status` (`pending|won|lost|refunded`),
  `actual_payout`, `created_at`, `settled_at`; **`UNIQUE(user_id, irl_match_id)`** — «одна ставка» на
  уровне БД, а не только в коде; `CHECK(amount BETWEEN 1 AND 1000)`.

Деньги идут через существующие `deduct_coins` / `add_coins` (re-entrant внутри `transaction()`):
списание и вставка `irl_bets` — одна транзакция, выплата и смена статуса — одна транзакция,
`tx_type` = `irl_bet_placed` / `irl_bet_won` / `irl_bet_refund`, `reference_id` = id ставки.
Все SQL — в `database.py`, время — только MSK (`time_utils`, `datetime('now','+3 hours')`).

**Слои (по образцу существующих):**
- `services/sports/adapters/api_sports.py` — добавить **предматчевые** методы. Сейчас `get_odds`
  ходит в `odds/live` (лайв-коэффициенты), а `get_fixtures` не принимает лигу и сезон. Нужны
  `fixtures?date=&league=&season=`, `odds?fixture=&bookmaker=` и чтение `score.fulltime`.
- `services/irl_betting.py` — чистая логика: выбор матча (`pick_top_matches`), валидация ставки,
  расчёт исхода (`settle_outcome`). Без сети и без БД — тестируется напрямую.
- `services/irl_jobs.py` — три джоба через `_run_repeating`: `irl_pick` (выбор + превью админам),
  `irl_odds_refresh` (обновление кэфов до начала матча), `irl_settle` (расчёт).
- `api/routes_irl.py` — `GET /api/irl/today`, `POST /api/irl/bets`, `GET /api/irl/bets/mine`.
  Авторизация и `check_user_access` как в `routes_predictions.py`.
- `web/` — раздел «Реальные матчи» в Mini App: карточка матча, три кэфа, поле суммы (≤ 1000),
  статус своей ставки.
- `handlers/admin_ops.py` или отдельный `handlers/admin_irl.py` — превью (ЛС глобальным админам),
  кнопки «Заменить / Добавить матч / Опубликовать / Отменить», `/irl_settle <id> <1|X|2|void>`.
  Регистрировать **до** AI catch-all; кнопки — в форме, которую понимает `test_production_audit`.
- `config.py` — все настройки: `IRL_ENABLED`, `IRL_BOOKMAKER_ID`, `IRL_COMPETITION_PRIORITY`, `IRL_TOP_TEAMS`,
  `IRL_MAX_BET` (1000), `IRL_MAX_MATCHES_PER_DAY`, `IRL_PREVIEW_HOUR_MSK`, `IRL_AUTO_PUBLISH_HOUR_MSK`.
- `admin_journal.record(...)` для публикации, замены, ручного расчёта + строки в `ACTIONS`.

## Behaviour

1. **Выбор.** В `IRL_PREVIEW_HOUR_MSK` джоб берёт игры на сегодня (МСК) по турнирам из
   `IRL_COMPETITION_PRIORITY` — единый список, где вперемешку клубные и **сборные** турниры
   (ЧМ, Евро, Кубок Америки, Лига наций, отбор на ЧМ/Евро, товарищеские матчи сборных). Берётся
   первый турнир, в котором сегодня есть подходящие матчи. Так в международные паузы день не
   остаётся пустым: клубные лиги в эти дни молчат, и выбор сам доходит до сборных. Внутри турнира
   выбирается топ-матч (см. Assumptions), при равных баллах — до `IRL_MAX_MATCHES_PER_DAY`.
   Матч без коэффициентов выбранного букмекера не подходит. Нет ни одного матча из списка →
   день без IRL-ставок, админу уходит короткое уведомление (не ошибка).
2. **Превью.** Матч создаётся как `draft`, глобальным админам уходит ЛС с кнопками.
3. **Публикация.** По кнопке «Опубликовать» — `open`. Если никто не нажал до
   `IRL_AUTO_PUBLISH_HOUR_MSK`, публикуется автоматически (иначе день остаётся пустым).
4. **Ставка.** Принимается, пока `status='open'` и `now < kickoff_at`; клиент присылает показанный
   кэф, при расхождении — `ODDS_CHANGED` (как в `place_user_bet`). Повторная ставка на матч → 409.
5. **Закрытие.** В `kickoff_at` матч становится `closed`; кэфы больше не обновляются.
6. **Расчёт.** `irl_settle` берёт `score.fulltime`, когда провайдер вернул `FT` и с начала матча
   прошло ≥ 100 минут. `AET`/`PEN` считаются по счёту после 90 минут. `PST`, `CANC`, `ABD`, `AWD`,
   `WO` → `void` и возврат ставок. Матч не завершён через 6 ч после старта → ЛС админам и ручной
   расчёт. Повторный расчёт не платит дважды (статус ставки меняется только из `pending`).
7. **Лимит выплаты.** Максимум 1000 × кэф; если кэф выше потолка из `betting_limits`, выплата
   режется до него — используем существующую константу, новую не заводим.

## Assumptions (подтвердите или поправьте)

1. **Топ-матч внутри турнира** считается по баллам. У сборных нет единой таблицы (отбор идёт по
   группам, на турнирах бывают плей-офф), поэтому место в таблице тут не работает. Балл = сколько
   команд матча входит в список `IRL_TOP_TEAMS` (сборные и клубы, правится в конфиге). Для клубных лиг
   добавляется бонус за места в таблице. При равных баллах побеждает более равный матч, то есть меньшая
   разница кэфов 1 и 2. Это эвристика; админ всегда может заменить матч.
2. **Авто-публикация**, если админ не ответил. Альтернатива — ничего не открывать без подтверждения.
3. **Кэфы обновляются** каждые 30 мин до старта, ставка хранит кэф на момент размещения. Если лимит
   запросов API-Sports мал, переключимся на «заморозить кэфы при публикации».
4. **Закрытие по времени старта**, без лайв-ставок.
5. **Видимость:** доступ как у остальных ставок (`check_user_access`, lockdown), отдельной роли нет.
6. **Сезон/дивизион:** IRL-ставки не привязаны к дивизиону и не входят в лимиты «Лимиты»/«Анализ
   рынка» (отдельная таблица). Новые `tx_type` учитываем, только если их читает аналитика кошелька.

## Risks and open questions

- **Тариф API-Sports неизвестен.** Он определяет лимит запросов в день, доступные сезоны и наличие
  предматчевых кэфов. Ключа я не вижу (`.env` закрыт хуком), нужен тестовый запрос на вашей стороне.
- **Какой букмекер?** Нужен `bookmaker_id` из API-Sports (например Pinnacle или Bet365) и проверка,
  что он отдаёт 1X2 по нужным лигам.
- **Список турниров по приоритету** — ваш выбор, клубные и сборные вместе. Для каждого нужен
  `league_id` из API-Sports. Пример порядка: ЧМ → Евро → Кубок Америки → ЛЧ → Лига наций → АПЛ →
  Ла Лига → Серия А → Бундеслига → Лига 1 → отбор на ЧМ/Евро → товарищеские матчи сборных.
- **Особенности сборных.** (а) Названия на разных языках и «U21/женские» команды с тем же именем:
  фильтруем по `league_id` и исключаем молодёжные и женские турниры. (б) Товарищеские матчи часто
  идут без предматчевых кэфов, тогда такой матч отпадает на шаге выбора. (в) В плей-офф ЧМ и Евро
  бывают допвремя и пенальти, 1X2 по-прежнему считается по счёту после 90 минут, об этом нужна
  пометка в карточке матча. (г) Несколько матчей в один час: берём до `IRL_MAX_MATCHES_PER_DAY`.
- **Название клубов.** Реальные клубы пересекаются по названиям с клубами лиги (`Реал`, `Интер`,
  `Манчестер Сити`). Это разные сущности, поэтому в IRL-таблице имена хранятся как есть от провайдера
  и **не** проходят через `resolve_team_name`.
- **Логотипы** реальных клубов не заводим в первой версии, только текст.

## Testing

`tests/test_irl_betting.py` (+ `test_irl_api.py` для роутов): выбор лиги и матча; одна ставка на
матч (UNIQUE) и гонка двух одновременных запросов; лимит 1000 и сумма ≤ 0; ставка после старта;
`ODDS_CHANGED`; расчёт 1/X/2, овертайм и пенальти, перенос/отмена; повторный расчёт не платит дважды;
баланс и `coin_transactions` сходятся; MSK-статический скан (`test_msk_time.py`) проходит.
Сеть мокается через `mock_provider`; реальный API в тестах не вызывается.

## Rollout

Миграция `035` аддитивная. Всё за флагом `IRL_ENABLED=false` по умолчанию: роуты отдают 404,
джобы не регистрируются. Сначала включаем на dry-run (превью админам без публикации), потом боевой
режим.
