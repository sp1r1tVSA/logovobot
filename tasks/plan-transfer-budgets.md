## 1. Концепция и математическая модель

### 1.1. Базовая формула
Итоговый бюджет клуба рассчитывается как сумма четырёх независимых компонентов:

$$\text{Итоговый бюджет} = \text{База дивизиона} + \text{Бонус за место в 1-м круге} + \text{Бонус за Общий кубок} + \text{Бонус за Кубок дивизиона}$$

### 1.2. Компоненты формулы (настраиваемые параметры)
1. **Базовый бюджет дивизиона ($\text{Base}$):**
   * Гарантированная сумма каждому клубу соответствующего дивизиона (например: Д1 — 80 млн, Д2 — 70 млн, Д3 — 60 млн и т.д.).
2. **Призовые за место в 1-м круге ($\text{League}$):**
   * Сетка вознаграждений за итоговую позицию в таблице 1-го круга (1-е место — максимальный бонус, последнее — минимальный или 0).
   * Определение границы 1-го круга: заданный номер тура $N$ (например, 15-й тур для 16 команд) либо автоматический расчёт по формуле $\lfloor(\text{всего туров}) / 2\rfloor$.
3. **Бонус за Общий кубок ($\text{Cup}_{\text{general}}$):**
   * Фиксированная выплата за наивысшую достигнутую стадию в междивизионном кубке:
     * 1/32, 1/16, 1/8, 1/4, 1/2, финалист, обладатель кубка.
4. **Бонус за Кубок дивизиона ($\text{Cup}_{\text{div}}$):**
   * Выплата за результат во внутреннем кубке своего дивизиона:
     * 1/8, 1/4, 1/2, финалист, обладатель кубка.

> **Пример расчёта:**
> Клуб из Д2: База (70 млн) + 3-е место в 1-м круге (+35 млн) + 1/4 финала Общего кубка (+15 млн) + Победа в Кубке Д2 (+25 млн) = **145 млн**.

## 2. Архитектура данных и бэкенд

### 2.1. Конфигурация формулы (`transfers/budget_rules.py`)
Все числовые коэффициенты выносятся в отдельный конфиг без зашивания в логику:
* Таблица базовых бюджетов по дивизионам `BASE_BUDGETS_BY_DIVISION: dict[int, int]`.
* Таблица выплат за места в лиге `LEAGUE_PLACE_REWARDS: dict[int, dict[int, int]]` (дивизион → место → сумма).
* Таблица выплат за стадии кубков `CUP_STAGE_REWARDS: dict[str, int]`.

### 2.2. Движок расчёта (`transfers/budget_calculator.py`)
Сервисный модуль для сбора статистики и калькуляции:
1. **Турнирная таблица 1-го круга:** вызов `database.get_standings(division_id=div_id, season_id=season_id, up_to_round=cutoff_round)` — получает фактические позиции клубов на момент завершения первого круга.
2. **Общий кубок:** обход стадий через `database.get_cup_full_bracket(division_id=None, season_id=season_id)` и вычисление наивысшей пройденной стадии для каждого клуба.
3. **Кубки дивизионов:** аналогичный обход через `database.get_cup_full_bracket(division_id=div_id, season_id=season_id)`.
4. Формирование структуры данных с подробной детализацией для каждого клуба:
   ```python
   {
       "club_name": "Arsenal",
       "division_id": 1,
       "base_k": 80_000,
       "league_place": 2,
       "league_bonus_k": 40_000,
       "general_cup_stage": "1/4",
       "general_cup_bonus_k": 15_000,
       "division_cup_stage": "winner",
       "division_cup_bonus_k": 30_000,
       "total_k": 165_000,
   }
   ```

### 2.3. Интеграция в модуль ТО
* Подключение расчёта в `transfers/service.py:default_budgets(window_id)` вместо заглушки `return {}`.
* Запись результатов через `transfers/service.py:apply_default_budgets()` в таблицу `transfer_club_budgets` со статусом `source = 'rule'`.
* **Защита ручных правок:** сохранение логики `overwrite_manual=False` — если администратор ранее вручную скорректировал бюджет клуба (`source = 'manual'`), автоматический расчёт не перетирает эти значения.
* Сохранение детализации расчёта (JSON-разбивка) для прозрачного отображения в интерфейсах.

## 3. Интерфейс администратора (Telegram-бот `/to`)

1. **Кнопка «🏆 Рассчитать бюджеты (1-й круг + кубки)»:**
   * Запрос номера тура отсечки (с подсказкой номера тура середины сезона по умолчанию).
2. **Экран предварительного просмотра (Превью):**
   * Сводка перед применением:
     * Количество рассчитанных клубов.
     * Топ-3 клуба по бюджету, клуб с минимальным бюджетом, средний бюджет по лиге.
   * Кнопки: **✅ Применить бюджеты** / **📄 Подробный отчёт (CSV/текст)** / **❌ Отмена**.
3. **Ручные корректировки:**
   * Возможность в любой момент точечно изменить бюджет конкретного клуба (штрафы, поощрения) с автоматической сменой статуса на `manual`.

## 4. Интерфейс для тренеров (Telegram Mini App)

Во вкладке «📊 Статус» (`web/js/transfers.js`):
* Добавление раскрывающегося блока **«Детализация бюджета»**:
  * 🏛 Базовый бюджет дивизиона: `XX млн`
  * 🏅 N-е место в 1-м круге: `+YY млн`
  * 🏆 Общий кубок (стадия): `+ZZ млн`
  * 🥇 Кубок дивизиона (стадия): `+WW млн`
  * **Итоговый бюджет: `TOTAL млн`**
* Исключает споры и вопросы тренеров касательно справедливости распределения средств.
